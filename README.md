# UE_Learning

Учебный проект на Unreal Engine 5.7 для выполнения домашних работ по курсу Unreal Engine Game Developer.

## Домашняя работа 1

Создан C++ проект на основе шаблона Unreal Engine и размещён в Git-репозитории.

Реализован плагин `HomeworkPlugin`, который создаёт визуальный объект на сцене. После правок по замечаниям преподавателя объект вынесен в отдельный Blueprint-ассет `BP_HomeworkCube`, а плагин спавнит уже готовый Actor, а не собирает куб полностью из кода.

Также реализован автоматический тест.

## Домашняя работа 2

Создана базовая C++ архитектура персонажа:

- `TPBaseCharacter` — базовый класс персонажа;
- `TPPlayerCharacter` — класс игрока на основе базового персонажа;
- `TPAttributeSet` — заготовка под атрибуты Gameplay Ability System;
- `TPInteractable` — интерфейс взаимодействия;
- `TPGA_Dash` — тестовая Gameplay Ability для рывка.

Настроено управление персонажем через Enhanced Input:

- движение;
- обзор мышью;
- прыжок;
- приседание;
- взаимодействие;
- рывок.

Персонаж подключён через Blueprint-наследник `BP_TPPlayerCharacter`.

## Домашняя работа 3

Добавлен новый персонаж `Alien Soldier` с набором анимаций.

Настроена анимационная система:

- `ABP_AlienSoldier`;
- Blend Space для обычного движения;
- Blend Space для движения в приседе;
- режим ходьбы;
- режим бега;
- режим спринта;
- прыжок с отдельными анимациями старта, полёта и приземления;
- режим прицеливания стоя;
- режим прицеливания в приседе;
- предсказание приземления через трассировку вниз;
- IK для левой руки при удержании оружия.

Добавлено оружие персонажа:

- C++ класс `TPWeaponActor`;
- Blueprint оружия `BP_RifleWeapon`;
- оружие задаётся через настройку `Weapon Class` в `BP_TPPlayerCharacter`;
- оружие крепится к сокету на скелете персонажа;
- левая рука подтягивается к IK-точке на оружии.

Создан отдельный модуль `HW3Module`, содержащий тестовый C++ Actor.

Создан отдельный плагин `HW3Plugin`, содержащий тестовый C++ Actor.

В классе персонажа добавлены функции для создания тестовых акторов из модуля и плагина перед игроком. Для вызова этих функций настроены отдельные клавиши через Enhanced Input.
