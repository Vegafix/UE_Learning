# UE_Learning

Учебный проект на Unreal Engine 5.7 для выполнения домашних работ по курсу Unreal Engine Game Developer.

## Домашняя работа 1

Создан C++ проект Unreal Engine и размещён в Git-репозитории.

Реализован автоматический тест `UE_Learning.PlayerControllerDefaults`, который проверяет валидность CDO пользовательского `AUE_LearningPlayerController`.

Создан плагин `HomeworkPlugin`, который при запуске игрового мира создаёт визуальный объект перед игроком.

После замечаний преподавателя плагин был доработан:

- `AUE_LearningGameMode` и `AUE_LearningPlayerController` связаны в C++ коде;
- визуальный объект вынесен в отдельный Blueprint-ассет `BP_HomeworkCube`;
- плагин спавнит готовый Actor через `SpawnActor`;
- лишние вызовы настройки масштаба и пробуждения физики удалены.

## Домашняя работа 2

Создана базовая C++ архитектура персонажа:

- `TPBaseCharacter` — базовый класс персонажа;
- `TPPlayerCharacter` — класс игрока на основе базового персонажа;
- `TPAttributeSet` — заготовка под атрибуты Gameplay Ability System;
- `TPInteractable` — интерфейс взаимодействия;
- `TPGA_Dash` — тестовая Gameplay Ability для рывка.

Настроено управление через Enhanced Input:

- движение;
- обзор мышью;
- прыжок;
- приседание;
- взаимодействие;
- рывок.

Персонаж подключён через Blueprint-наследник `BP_TPPlayerCharacter`.

После замечания преподавателя часть числовых параметров вынесена из кода в именованные `UPROPERTY`:

- длина камеры;
- дистанция взаимодействия;
- расстояние спавна тестовых акторов;
- высота спавна тестовых акторов;
- скорость поворота персонажа;
- скорости движения.

Это убирает магические числа из основной логики и позволяет настраивать параметры через Blueprint.

## Домашняя работа 3

Добавлен персонаж `Alien Soldier` с набором дополнительных анимаций.

Настроена анимационная система:

- `ABP_AlienSoldier`;
- Blend Space для обычного движения;
- Blend Space для движения в приседе;
- ходьба;
- бег;
- спринт;
- прыжок со стартом, фазой полёта и приземлением;
- прицеливание стоя;
- прицеливание в приседе;
- IK для левой руки при удержании оружия.

Добавлено оружие персонажа:

- C++ класс `TPWeaponActor`;
- Blueprint оружия `BP_RifleWeapon`;
- оружие задаётся через настройку `Weapon Class` в `BP_TPPlayerCharacter`;
- оружие крепится к сокету на скелете персонажа;
- левая рука подтягивается к IK-точке на оружии.

Создан отдельный модуль `HW3Module`, содержащий тестовый C++ Actor.

Создан отдельный плагин `HW3Plugin`, содержащий тестовый C++ Actor.

В классе персонажа добавлены функции для создания тестовых акторов из модуля и плагина перед игроком.  
Для вызова этих функций настроены отдельные клавиши через Enhanced Input.

После замечаний преподавателя была доработана архитектура персонажа:

- Blueprint-геттеры состояния персонажа вынесены в публичный интерфейс;
- геттеры состояния сделаны `BlueprintPure`;
- независимые булевые флаги движения заменены на `ETPMovementState`;
- режимы `Running`, `Walking`, `Sprinting`, `Aiming` теперь представлены через `enum class`;
- скорость и режим поворота обновляются централизованно через `SetMovementState`;
- предсказание приземления сохранено, но оптимизировано: трассировка вниз запускается только во время падения через таймер, а не каждый `Tick`.
